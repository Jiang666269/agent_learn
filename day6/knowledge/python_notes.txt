Python 是一种高级解释型编程语言，语法简洁，常用于数据分析、人工智能、自动化脚本、Web 开发和科学计算。

Python 中常见的数据结构包括列表、元组、字典和集合。列表是可变序列，可以增加、删除和修改元素。

元组与列表类似，但元组通常是不可变的。创建元组以后，其中元素的整体结构通常不能直接修改。

Python 字典使用键值对存储数据。例如 student = {"name": "Tom", "age": 20}。可以通过键快速访问对应的值。

Python 中使用 def 定义函数。函数可以接收参数，也可以通过 return 返回结果。函数能够减少重复代码，提高程序的模块化程度。

for 循环常用于遍历列表、字符串、字典等可迭代对象。enumerate() 是 Python 的内置函数，可以在遍历元素的同时获得元素的下标。

Python 中的类使用 class 定义。对象是类的实例。面向对象编程通常涉及封装、继承和多态等概念。

Python 可以使用 pip 安装第三方库。例如 numpy 常用于数值计算，pandas 常用于数据分析，requests 常用于发送 HTTP 请求。
