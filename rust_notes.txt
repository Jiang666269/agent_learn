一、Rust 简介

Rust 是一门由 Mozilla 主导开发的系统级编程语言，首个稳定版本于 2015 年发布。它的设计目标是同时兼顾安全性、并发性和性能。Rust 在不依赖垃圾回收机制的前提下，通过所有权和借用检查在编译期消除内存安全问题，因此常被用于操作系统、嵌入式、网络服务、区块链和命令行工具等领域。连续多年，Rust 都被开发者评为最受喜爱的编程语言。

二、环境搭建与工具链

Rust 的官方工具链管理工具是 rustup，通过它可以安装、更新和切换不同版本的 Rust。常用组件包括：rustc，即 Rust 编译器；cargo，官方包管理和构建工具；rustfmt，代码格式化工具；clippy，静态检查工具，用于发现常见错误和不良写法。

创建新项目可使用 cargo new 项目名，编译运行使用 cargo build 和 cargo run，测试使用 cargo test，发布构建使用 cargo build --release。

三、基础语法

Rust 使用 let 声明变量，默认不可变，需要修改时加 mut。基本数据类型包括整数（i8 到 i128、u8 到 u128）、浮点数（f32、f64）、布尔值 bool、字符 char，以及字符串切片 &str 和可增长字符串 String。复合类型主要有元组和数组。

函数使用 fn 定义，参数和返回值都必须标注类型。Rust 是表达式语言，函数最后一个表达式的值即为返回值，无需写 return。控制流包括 if、loop、while 和 for，其中 if 可以作为表达式赋值。

四、所有权与借用

所有权是 Rust 最核心的概念，规则有三条：每个值都有一个所有者；同一时间只能有一个所有者；所有者离开作用域时值被自动释放。变量赋值或传参时可能发生移动，原变量随即失效。若希望复制简单数据，可使用 Copy 类型；若希望保留原值，可调用 clone。

借用允许在不转移所有权的情况下使用值：&T 为不可变引用，&mut T 为可变引用。同一作用域内，要么存在多个不可变引用，要么只能存在一个可变引用，二者不可同时存在。这一规则从根本上避免了数据竞争。

五、结构体、枚举与模式匹配

结构体用 struct 定义，可为字段和方法（impl 块）组织数据。枚举用 enum 定义，可以携带数据，最典型的是标准库中的 Option 和 Result。match 是强大的模式匹配工具，必须穷尽所有可能分支；if let 和 while let 则用于简化单一模式的匹配。

六、错误处理

Rust 将错误分为可恢复错误和不可恢复错误。可恢复错误用 Result 表示，通过 match、问号运算符或组合器处理；不可恢复错误使用 panic! 宏，程序会立即终止并展开栈。问号运算符能在错误时提前返回，是编写简洁错误传播代码的关键。

七、泛型、Trait 与生命周期

泛型让代码可以适配多种类型，减少重复。Trait 定义共享行为，类似其他语言的接口，可实现多态。生命周期用单引号加名称标注，用于告诉编译器引用的有效范围，最常见的场景是函数返回引用时。大多数情况下编译器能自动推断，无需手动标注。

八、并发与智能指针

Rust 提供线程、消息传递和共享状态等并发手段。其无畏并发得益于所有权和 Send、Sync 等 trait 的编译期检查。常用智能指针包括 Box，用于堆分配；Rc，引用计数；RefCell，内部可变性；以及 Arc，原子引用计数，用于多线程。

九、Cargo 与生态

Cargo 通过 Cargo.toml 管理依赖，crates.io 是官方包仓库。常用命令有 cargo add、cargo doc、cargo clippy 和 cargo fmt。Rust 生态中，Web 开发常用 Axum、Actix-web，异步运行时常用 Tokio，序列化常用 Serde，命令行工具常用 Clap。
